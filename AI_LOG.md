# AI_LOG

## Использование ИИ

При выполнении тестового задания использовал ChatGPT (Microsoft Copilot на базе GPT) как помощника при проектировании архитектуры, реализации отдельных частей функционала и подготовке документации.

Все предложенные решения проверялись вручную через запуск приложения, Swagger UI, Pytest, Docker Compose и GitHub Actions.

## Примеры запросов

Некоторые запросы, которые использовались в ходе работы:

- Как организовать структуру проекта?
- Как реализовать идемпотентность платежей через `Idempotency-Key`?
- Как корректно распределять остаток копеек при рассрочке?
- Как написать интеграционные тесты для FastAPI и PostgreSQL?
- Как настроить Docker Compose для FastAPI и PostgreSQL?
- Почему FastAPI стартует раньше PostgreSQL и как исправить это через healthcheck?
- Как запускать Pytest внутри Docker?
- Как настроить GitHub Actions для запуска Ruff и Pytest?

## Проверка результатов

Каждый этап проверялся вручную:

- тестирование эндпоинтов через Swagger UI;
- запуск интеграционных тестов;
- запуск приложения локально и в Docker;
- проверка прохождения GitHub Actions.

Часть предложений ИИ дорабатывалась или исправлялась после анализа ошибок и проверки на практике.

## Где модель ошиблась или предложила слабое решение

- При настройке Docker Compose первоначальное решение не учитывало ожидание готовности PostgreSQL. Проблема была обнаружена по логам, после чего был добавлен `healthcheck`.
- При запуске тестов внутри Docker использовались локальные настройки подключения (`127.0.0.1`). После проверки конфигурация была изменена на использование имени сервиса `postgres`.
- Ruff сообщал об ошибках `B008` для `Depends(...)` в FastAPI. После проверки документации выяснилось, что это стандартный и рекомендуемый способ использования зависимостей, поэтому правило было исключено из конфигурации Ruff.

## Итог

ИИ использовался как инструмент для ускорения разработки и обсуждения решений. Все основные части проекта были реализованы, протестированы и отлажены самостоятельно.
